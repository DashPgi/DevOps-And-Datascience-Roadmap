Images
docker info -> show informations
docker image -> show image's list 
docker pull nginx -> get a image from docker hub
docker build -t myapp -> create a image with myapp name
docker rmi nginx -> remove image
docker build . -> Create image with docker file
docker image save -o imagename.tar imageid  -> for save image 
docker image load -i imagename.tar -> for load image

docker run nginx -> create and run a Container
docker run -d nginx -> run container on background mode
docker ps -> show all running container
docker ps -a -> show all stoped container
docker stop mynginx -> stop Container
docker restart mynginx -> restart Container
docker rm mynginx -> remove Container


Volume
docker volume create volname -> create a volume
var/lib/docker -> where the volume is
docker volume create myvolume && docker run -v myvolume:/app/data myimage -> for normal vol
docker run --tmpfs /app/temp myimage -> for tmpfs 
docker run -v /home/user/project:/app myimage -> for Bind Mount
docer volume mount -> Link a dockervol to dockercontainer
docker run -v myvolume:/data:ro nginx -> set docker vol to Read-Only
docker run -v /app/data myimage ->  create a Anonymous

Networking
docker network create --drive drivestype -> create a new network
docker network connect -> connect a container to network
docker network ls -> list and show all network
docker network disconnect -> disconnect network
docker network  prune -> remove all unused network
docker network  inspect -> show all details

Compose
docker compose -f ['filepath' For custome name file .yml] up -> create and start a new container
