### Exact Numeric

- INT = 4 bytes
- BIGINT = 8 bytes
- BIT = 1, 0, NULL
- DECIMAL = 5–17 bytes
- MONEY = 8 bytes
- SMALLMONEY = 4 bytes

Used for storing binary data.

### XML

0–2 GB

### sql_variant

0–8000 bytes.

# VIEW

CREATE VIEW view_name AS (selected data) → Creates a CTE-like database object that can be used repeatedly.

DROP VIEW view_name → Removes the view.

### ALTER VIEW

ALTER VIEW view_name  
WITH ENCRYPTION  
AS ...

→ Encrypts the view's definition.

### WITH SCHEMABINDING

ALTER VIEW view_name  
WITH SCHEMABINDING  
AS ...

→ Sets the view's structure and prevents changes to the underlying objects that would invalidate the view.

### WITH CHECK OPTION

WITH CHECK OPTION → Sets a gate that controls data modifications according to the view's conditions.
